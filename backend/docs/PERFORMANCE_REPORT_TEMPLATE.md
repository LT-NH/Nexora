## 2. 如何运行

```bash
# 1) 启动后端
cd backend
python -m uvicorn app.main:app --port 8000

# 2) （可选）准备演示数据，让列表接口返回真实数据
python seed_demo.py

# 3) 执行压测
python load_test.py --base-url http://127.0.0.1:8000 --concurrency 10 --requests 500

# 覆盖更多场景：调整并发与请求量
python load_test.py --concurrency 20 --requests 1000
```

## 4. 指标含义

- **吞吐量 (req/s)**：单位时间内完成的请求数。反映系统容量，受并发、业务耗时、数据库性能影响。
  同场景多次取均值，避免单次抖动。
- **P50 / P95 延迟 (ms)**：延迟分布的百分位。
  - P50 代表「典型用户体验」；
  - P95 代表「高峰/尾部体验」。P95 与 P50 差距过大说明存在长尾慢请求（锁竞争、慢查询、GC 等）。
- **错误率 (%)**：请求失败占比。5% 为基准阈值；超阈值应视为回归，阻断发布。
- **总耗时**：在给定并发下跑完全部请求的时间。降低总耗时/提高吞吐意味着容量提升。
