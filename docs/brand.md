# Nexora 品牌规范

> 本文件是设计与实现之间的契约。任何新增页面、组件或对外物料都应能在这里找到依据。
> 最后更新：2026-09-16

---

## 1. 品牌定位

| 项 | 内容 |
|---|---|
| 名称 | Nexora |
| 一句话 | 一个面板，管理全部电商渠道 |
| 英文 slogan | One Core, All Commerce |
| 目标用户 | 中小电商经营者、多平台铺货的个人与团队 |
| 核心差异 | 不是报表工具，是给出下一步动作的经营决策系统 |

**语气**：直给、务实、不堆形容词。说「订单自动汇聚」而不是「赋能全渠道增长」。

## 2. 色彩

### 2.1 品牌主色

主色是一段 violet → fuchsia 的渐变关系，不是单一色值。

| 角色 | 色值 | Tailwind | 用途 |
|---|---|---|---|
| **品牌锚点色** | `#7c3aed` | `primary-600` | Logo、主按钮、链接、`theme-color` |
| 主色亮阶 | `#8b5cf6` | `primary-500` | 图表主序列、hover 态 |
| 渐变终点 | `#d946ef` | `fuchsia-500` | 标题高亮词、渐变扫光终点 |
| 渐变深阶 | `#6d28d9` | `primary-700` | 渐变中段、暗色悬停 |

品牌主渐变（登录页左栏、CTA）：

```
bg-gradient-to-br from-primary-600 via-primary-700 to-fuchsia-700
```

标题高亮渐变：

```
bg-gradient-to-r from-violet-600 via-purple-600 to-fuchsia-500
```

### 2.3 语义色使用规则

| 场景 | 颜色 | 说明 |
|---|---|---|
| 营收 / 利润 / 增长（正向） | `success` 绿 | — |
| 成本 / 亏损 / 下降 | `danger` 红 | — |
| 待处理 / 预警 | `warning` 琥珀 | — |
| 中性数据、次要文本 | `secondary` 灰 | — |
| 品牌强调、可交互 | `primary` 紫 | 一屏内不超过 2 处强强调 |

> **图表配色**：按 `success` / `danger` 语义走。中国市场惯例——**涨用红、跌用绿**仅在股票类场景适用；经营数据（销售额、利润）用**绿=好、红=差**，与产品内已有图表保持一致。

### 2.4 对比度要求

- 正文文本对背景对比度 ≥ 4.5:1
- 大号标题（≥24px）≥ 3:1
- **深色渐变背景上禁用 `primary-100` / `primary-200` 作正文**（实测对比度不足），改用 `text-white/85`、`text-white/65`

## 3. 字体

### 3.1 字体族

```
Plus Jakarta Sans  ← 数字、英文、品牌词
  ↓ 回退
-apple-system → BlinkMacSystemFont       (macOS)
PingFang SC → HarmonyOS Sans SC          (中文，移动端优先)
Microsoft YaHei → Noto Sans SC           (中文，Windows)
system-ui → sans-serif
```

字体自托管于 `public/fonts/PlusJakartaSans-Variable.woff2`（27 KB，可变字重），**不依赖 Google Fonts**。

### 3.2 字重

| 字重 | 用途 |
|---|---|
| 400 Regular | 正文、说明文字 |
| 500 Medium | 次级标题、标签 |
| 600 Semibold | 卡片标题、按钮 |
| 700 Bold | 页面主标题 |
| 300 Light | 首屏标题的对比行（如「一个面板，」） |

### 3.3 首屏标题字号阶梯

字号由**左侧列宽**决定，不由视口决定。中文标题约每行可容纳 `列宽 / 字号` 个字。

| 断点 | 字号 | 实测标题高 | 左列宽 |
|---|---|---|---|
| `<640` (手机) | 36px | 78px | 358px |
| `sm` (640+) | 60px | 120px | 720px |
| `lg` (1024+) | 72px | 216px | 448px |
| `xl` (1280+) | 80px | 240px | 576px |
| `2xl` (1536+) | 88px | 264px | 608px |

> **踩坑记录**：`lg` 断点左列仅 448px，若沿用 96px 会把标题折成 4 行（399px），
> 导致副文案与 CTA 全部掉到折叠线以下（实测 1024×768 下 CTA `bottom=944 > vh=768`）。
> 改 72px 后为 3 行 216px，CTA 回到 644px，折叠线内余量 124px。

## 4. 图标与图形资产

### 4.1 资产清单

| 文件 | 尺寸 | 体积 | 用途 |
|---|---|---|---|
| `favicon.ico` | 16/32/48 | 4.7 KB | 浏览器标签页（含旧浏览器兜底） |
| `favicon-32.png` | 32×32 | 1.4 KB | 现代浏览器标签页 |
| `favicon-192.png` | 192×192 | 21 KB | Android 主屏、侧边栏小图标 |
| `favicon-512.png` | 512×512 | 110 KB | PWA、启动屏、登录页大标识 |
| `nexora-logo.png` | 720×576 | 247 KB | 横版品牌图（Logo + 字标 + slogan） |
| `og.jpg` | 1200×630 | 58 KB | 社交分享卡片 |

原始高分辨率素材备份在 `.asset-originals/`（不进版本库）。

### 4.2 使用规则

- **方形场景**（favicon、侧边栏、头像位、PWA）→ 一律用 `favicon-*.png`，取自 N 图形标记
- **横版场景**（分享图、印刷、品牌展示）→ 用 `nexora-logo.png`
- 图标容器需为正方形并留 ≥12% 内边距，禁止拉伸变形（`object-contain`）
- 最小可辨识尺寸：**16px**（已实测 N 标记在 16px 下轮廓可辨）

> **踩坑记录**：`favicon.png` 与 `nexora-logo.png` 原本是同一个 790 KB 的 1402×1122 横版图，
> 被 6 处当方形图标引用。已拆分为「方形标记」与「横版品牌图」两套职责。

| 首屏顶部内边距 | `112px` / `128px` / `144px` | 手机 / 平板 / 桌面 |

## 6. 动效

所有动效必须遵守 `prefers-reduced-motion: reduce`（已在 `index.css` 全局处理）。

| 动效 | 时长 | 缓动 | 用途 |
|---|---|---|---|
| 页面入场 `pageIn` | 350ms | `cubic-bezier(0.22, 1, 0.36, 1)` | 路由切换 |
| 首屏标题 `heroTitleIn` | 900ms | 同上 | 上浮 + 模糊渐显 |
| 控制台入场 `consoleIn` | 1000ms | 同上（延迟 350ms） | 3D 透视入场 |
| 卡片悬浮 | 300ms | 同上 | 抬升 |
| CTA 呼吸 | 3500ms 循环 | `ease-in-out` | 主按钮引导 |
| 视图转场 | 320ms | 同上 | View Transitions API |

原则：**入场用弹性缓动（快起慢收），循环动效幅度要小**。禁止超过 1s 的循环动画。

## 7. 文案规范

### 7.1 标题

- 主标题用陈述句，不用疑问句、不用感叹号
- 中文标题末尾不加句号（视觉上留白处理）
- 避免「赋能」「闭环」「生态」等词

### 7.2 按钮

| 类型 | 文案 | 反例 |
|---|---|---|
| 主 CTA | 开始免费试用 | 立即体验 → 太虚 |
| 次要 | 查看功能 | 了解更多 → 不具体 |
| 提交 | 保存 / 创建 | 确定 → 不说明结果 |

### 7.3 数据表述

- 有具体数字就用具体数字：「14 天免费试用」优于「长期免费试用」
- 不夸大：「5 分钟接入」需真实可达
- **禁止编造数据**。演示数据必须标明来源，AI 输出必须来自真实模型调用

## 8. 落地检查清单

新增页面上线前逐项确认：

- [ ] 主色使用 `primary-600`，未引入体系外的紫色
- [ ] 渐变背景上的文字对比度达标（实测，非目测）
- [ ] 首屏 CTA 在 1024×768 下位于折叠线之上
- [ ] 全部断点无横向溢出（`scrollWidth <= innerWidth`）
- [ ] 方形场景用 `favicon-*`，未误用横版品牌图
- [ ] 动效有 `prefers-reduced-motion` 降级
- [ ] 图标容器正方形 + `object-contain`
